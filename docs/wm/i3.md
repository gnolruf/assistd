# Getting Started with i3

i3 config snippets for `assistd`. Read the
[shared setup page](README.md) first: it covers the hotkeys,
what each command does, and how to verify the result.

## Terminal

The scratchpad snippet matches the chat's terminal by X11 `WM_CLASS`.
The snippets use `alacritty --class assistd-tui`; `kitty --class
assistd-tui` and `wezterm start --class assistd-tui` work the same way.

## Auto-start the daemon and tray

```i3config
exec --no-startup-id assistd daemon
exec --no-startup-id assistd tray
```

To use the systemd user unit instead of the first line:

```i3config
exec --no-startup-id systemctl --user import-environment DISPLAY I3SOCK && systemctl --user start assistd
```

`i3bar` only hosts XEmbed tray icons, and `assistd tray` is
StatusNotifierItem-only, so run an SNI host: a bar with native SNI
support, or an XEmbed bridge such as `snixembed` in front of i3bar or
Polybar.

## Hotkeys

i3 cannot add bindings over IPC, so the daemon grabs `[hotkeys]` on the
X11 root window instead. Push-to-talk needs no lines in the i3 config;
remove any `bindsym … exec assistd …` lines for the same keys.

The stock i3 config binds `$mod+space` to `focus mode_toggle`, and i3
holds its own bindings' grabs, so the daemon's grab of `Super+Space`
fails. Remove that line or pick another key.

## Presence

```i3config
bindsym $mod+Shift+Escape exec --no-startup-id assistd sleep
bindsym $mod+Shift+w      exec --no-startup-id assistd wake
```

## Chat scratchpad

```i3config
exec --no-startup-id alacritty --class assistd-tui -e assistd chat --wait

for_window [class="assistd-tui"] floating enable, move scratchpad, \
            resize set 1200 800, move position center

bindsym $mod+grave [class="assistd-tui"] scratchpad show
```

If the scratchpad never appears, run `xprop`, click the chat's
terminal, and confirm `WM_CLASS(STRING) = "assistd-tui", "assistd-tui"`.

## Optional: continuous listening and TTS

```toml
[hotkeys]
toggle_listening = "Super+Shift+L"
toggle_speech = "Super+Shift+M"
skip_speech = "Super+Shift+S"
```
